# Code of Conduct

LLM-Brain is a technical project built around privacy, inspectability and
good-faith collaboration. Keep project spaces useful, safe and focused on the
work.

## Expected behaviour

- Be respectful, professional and specific.
- Discuss ideas, evidence and implementation choices rather than attacking
  people.
- Welcome questions and correct mistakes without humiliation.
- Protect privacy: never post vault records, credentials, customer or patient
  data, private infrastructure details or other sensitive material.
- Keep reports and reviews reproducible, scoped and in good faith.

## Unacceptable behaviour

- Harassment, threats, personal attacks, discrimination or unwanted
  sexualised conduct.
- Doxxing, publishing private or sensitive data, or attempting unauthorised
  access.
- Spam, impersonation, deliberate disruption or bad-faith issue and review
  activity.
- Retaliation against someone who raises a concern in good faith.

## Scope and enforcement

This code applies in repository issues, discussions, pull requests, reviews,
and project-related events or communication. Maintainers may edit or remove
content, close issues or pull requests, or limit participation when behaviour
breaches this code or threatens project safety. Enforcement decisions should
be proportionate, documented where practical, and applied consistently.

## Reporting

Report conduct concerns privately to the repository maintainers through GitHub.
Do not include private data in a public issue. For suspected vulnerabilities,
follow [`SECURITY.md`](SECURITY.md) instead.
