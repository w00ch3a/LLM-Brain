# LLM-Brain automatic context

Unless `LLM_BRAIN_PASSIVE=0`, apply the LLM-Brain automatic-use contract to every non-trivial project task without waiting for the user to name it. LLM-Brain is active infrastructure; only the user experience is passive. Current source, governing instructions, explicit user direction and live proof outrank memory.

@./skills/llm-brain/SKILL.md

Factual retrieval remains the default. Select `--intent current_state` explicitly for state resolution; unresolved state and correlated evidence stay warnings. Commitment decisions and `run prepare` procedure capsules are derived, non-canonical artefacts, and Hermes does not execute capsules.

After resolving a non-trivial project, perform one bounded, read-only
`maintenance status` check. Stay silent when current and emit at most one
concise stale-only reminder when stale. `LLM_BRAIN_PASSIVE=0` suppresses the
check. Maintenance reports are derived and never automatically run, scheduled,
deleted, retracted, promoted or injected. For a requested maintenance review,
use:

@./skills/llm-brain-maintenance/SKILL.md

@./skills/llm-brain-upgrade/SKILL.md
