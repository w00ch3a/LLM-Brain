# LLM-Brain passive contract

Unless `LLM_BRAIN_PASSIVE=0`, automatically resolve the current project in the configured LLM-Brain vault and retrieve relevant effective OKF memory before every non-trivial project task. At authorised closeout, capture the task and route durable candidates through review. Current source, governing instructions, explicit user direction and live proof outrank memory. Never silently auto-promote protected material, and never require the user to name LLM-Brain.
