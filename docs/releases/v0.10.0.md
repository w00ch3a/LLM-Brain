# LLM-Brain v0.10.0

Prepared 2026-10-19. Not yet released.

This release closes silent failure modes and adds safer belief updates,
handover between sessions and agents, and fuller recall for sub-agents and
after host compaction. It also includes the Neural Expansion work for Hermes
Desktop since 0.9.2.

Storage schema 3 and canonical OKF v0.2 are unchanged. No vault migration is
needed and no canonical record is rewritten. New data lives in new side files
(`writer.format`, `ruled-out/items.tsv`, attempt diffs in `sources/`) that
0.9.x builds ignore.

Everything that costs tokens or compute is either very small (a few lines in
a brief or pack, and only when there is something to say) or opt-in. Defaults
are listed at the end.

## Upgrade note for shared vaults (read first)

0.10 records a writer format level in `writer.format` at the vault root. A
build with a lower level refuses to write to that vault (exit 75) and asks you
to upgrade that machine first. 0.9.x builds predate the guard and cannot be
stopped by it, so **upgrade every machine that shares a vault (for example on
a NAS) at the same time.** `LLM_BRAIN_WRITER_GUARD=0` is an emergency
override.

## Fixes

1. **Evidence views and `---`.** A `---` inside a frontmatter value or the
   body no longer splits the record in the wrong place, which could leak
   frontmatter into evidence views and lose body text after a horizontal rule.
   Cached evidence views are rebuilt when their line counts change; run
   `llm-brain index build PROJECT` once to refresh them all.
2. **Historical packs say what was replaced.** `pack build --historical` and
   `--as-of` label each record: `HISTORICAL, superseded by X (Title) on DATE`,
   `CURRENT as of DATE`, `OLDER VALUE`, `EXPIRED` or `RETRACTED`, in observed
   time order. Default packs are unchanged.
3. **Search and recall are much faster.** Each query used to start about 25
   helper processes per record (a Python YAML check, hashing and field reads)
   and re-check every record again for the vector pass. Search now checks
   eligibility, hashes and BM25F scores every record in one Python pass,
   reads each record's fields once, and renders result rows in one call.
   Recall shares one field cache across search and rendering. Results and
   ranking are unchanged, and the old per-record path is kept as a fallback.
   On a 400-600 record test vault a search query went from 55-145 s to
   0.7-1.9 s, and a full bridge recall takes about 1.5-3 s. This matters
   most on a Pi with the 10 s recall timeout.

## Continuity

3. **Session handover.** `brief --since ISO` adds "Since your last session"
   (up to 8 approved changes). `brief --session ID` adds "Other agents' open
   work here", flagging two agents touching the same path or state key. The
   Claude SessionStart hook keeps a host-side marker (outside the vault) and
   passes `--since` automatically. `LLM_BRAIN_HANDOVER=0` turns it off.
4. **Already ruled out.** `ruled-out add|reopen|list` keeps an append-only,
   audited, principal-scoped ledger of approaches that were tried and failed.
   Matching items appear in packs and bridge recall under "Already Ruled Out".
5. **Forgotten saves.** `forgotten PROJECT [--days N]` lists records never
   recalled (needs retrieval receipts) and stale intentions and working items.
   `LLM_BRAIN_RECEIPTS=1` turns receipts on for search, packs and bridge
   recall; without it the report says it cannot know.
12. **Recall after compaction and for sub-agents.** After host compaction
   the SessionStart hook re-attaches the newest pack built since the last
   start, once, capped at 2500 bytes (`LLM_BRAIN_REATTACH_BYTES`;
   `LLM_BRAIN_COMPACT_REATTACH=0` turns it off). A SubagentStart hook gives
   sub-agents a 1500-byte brief when `LLM_BRAIN_SUBAGENT_RECALL=1` (off by
   default). The hook reads host JSON only when called with `--stdin`.

## Silent failures and safety

6. **Health checks.** `health PROJECT|--all` (read-only) checks for broken
   frontmatter, metadata smuggled into a body, unproven human verification,
   near-duplicate names, near-colliding state keys, mass rewrites and dropped
   host configuration, and gives a 0–100 score. `--fail-under N` and
   `doctor --fail-under N` make it usable in scripts.
7. **Automatic capture tags.** Reflection candidates are tagged `fact`,
   `hypothetical` or `proposal` deterministically, with no human step. Only
   facts can be promoted. A person who agrees with a proposal can promote it
   with `review decide … approved --as-fact` (audited).
8. **Version guard.** See the upgrade note above.
9. **Privacy between people.** Gate reports no longer match or count records
   scoped to another principal. `LLM_BRAIN_STRICT_PRINCIPAL=1` (opt-in) hides
   principal-scoped records from callers that give no principal. Sensitive
   topics are not filtered out; this is a personal brain.
10. **Forgetting that sticks.** After `retract --confirm`, the record is gone
   from search, packs, bridge recall, folder summaries, derived projections and
   Neural Expansion exports, while other summary lines stay. `--preview` lists
   records from which it could be inferred again (links, shared state key,
   association partners, near-restatements) so you can decide about them. The
   tombstone and lineage stay; the original file is kept as custody.
11. **Careful belief updates.** A record that would supersede a fact backed by
   more independent sources than it has is held for review with a `belief_`
   conflict record instead of overwriting the fact. It is promoted as soon as
   enough independent sources agree. A person can overrule with
   `review decide … approved --overrule-belief` (audited). Single-source facts
   update as before. `LLM_BRAIN_BELIEF_MIN_SUPPORT` (default 2) sets when a
   fact counts as well supported.

## Procedures and code

13. **Procedure lifecycle.** `procedures PROJECT` shows a derived
   `trial`/`active`/`stable`/`retired` state per procedure, based on the most
   recent runs since the procedure, its evidence, its dependencies or (with
   `--source-root`) its anchored code last changed. Earlier wins do not carry
   over a change. Runs now record the procedure hash. `brain_contrasts` links
   near-identical opposite procedures (upgrade and rollback); packs warn about
   them and flag retired procedures. States also appear as `procedure:STATE`
   derived labels.
14. **Tried and reverted.** `attempt record PROJECT --title T (--diff FILE |
   --git-range A..B | --commit SHA)` keeps the real diff in `sources/` with a
   checksum, linked to its decision, after a secret scan and a size cap
   (`LLM_BRAIN_ATTEMPT_MAX_BYTES`, default 200000). Packs list matching attempts
   in one line each and attach capped diff excerpts only with
   `--require-evidence`. `attempt list|show` reads them back.

## Evaluation

15. `scripts/eval-outcome.py --controls` adds blind shuffled-memory and
   unrelated-memory control arms and reports the lift over the best control.
   `scripts/eval-lifecycle.py --step-checks` scores each write event's actual
   store operation (create, update, reinforce, supersede, retract). Both are
   opt-in.

## Neural Expansion for Hermes (since 0.9.2)

- Hermes Desktop Neural Expansion page; project picker (counts only);
  View all (all projects) merged graph built in parallel with progress.
- Pending review-queue items shown as unreviewed (principal-filtered, capped,
  with a hide toggle); served copies removed; longer export timeout for large
  review queues.
- `reflect submit` creates `reflection/commitments/` in older projects instead
  of failing.

## Defaults

| Behaviour | Default |
|---|---|
| Handover in the Claude hook | on (`LLM_BRAIN_HANDOVER=0` to disable) |
| Pack re-attach after compaction | on, once, 2500 bytes (`LLM_BRAIN_COMPACT_REATTACH=0`) |
| Sub-agent brief | off (`LLM_BRAIN_SUBAGENT_RECALL=1`) |
| Retrieval receipts | off (`LLM_BRAIN_RECEIPTS=1`) |
| Strict principal scoping | off (`LLM_BRAIN_STRICT_PRINCIPAL=1`) |
| Writer guard | on (`LLM_BRAIN_WRITER_GUARD=0` override) |
| Belief hold threshold | 2 independent sources (`LLM_BRAIN_BELIEF_MIN_SUPPORT`) |
| Code-change reset for procedures | only with `procedures --source-root` |
| Diff excerpts in packs | only with `--require-evidence` |
| Eval control arms, step checks | off (`--controls`, `--step-checks`) |
