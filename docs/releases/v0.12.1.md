# Memthena v0.12.1 (formerly LLM-Brain)

Released 2026-10-26.

Patch release.

## Fix

- **`doctor` no longer reports OKF folder index pages as records.** After
  `migrate okf-backfill --apply`, `doctor` could report
  `missing validation timestamp` for the generated per-folder `index.md` pages
  in projects still on a pre-schema-3 OKF bundle. OKF v0.2 reserves `index.md`
  and `log.md` for navigation, so `doctor` now skips them in its record checks,
  as every other record path already did. A file with one of those names that
  carries record frontmatter is still checked as a record, and a real record
  without a validation timestamp is still reported. `lint` was not affected.

## Upgrade notes

- No vault migration. Storage schema 3, OKF v0.2 and the writer format are
  unchanged, so 0.12.0 and 0.12.1 can share a vault.
- Nothing in the vault needs to change: the backfill's index pages were
  correct; only the `doctor` report was wrong.
