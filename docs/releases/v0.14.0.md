# Memthena v0.14.0 (formerly LLM-Brain)

Released 2026-11-17.

Seven memory-quality and safety changes. Each change has its own behavioural
self-check, and all of them run in the release gate. Pack layout is opt-in;
the default pack remains the 0.13 ranked layout.

## Safety and correctness

- **Safeguard-relaxing memories stay scoped to their task.** A lesson that
  would skip a test or confirmation, auto-approve, or pass `--no-verify` is
  tagged `brain_relaxes_safeguard` and held at promotion until it names a
  task (`review decide ... --applies-when 'task=TYPE'`, audit
  `applies-when-set`). It is packed only for that task.
  `LLM_BRAIN_SAFEGUARD_SCOPE=0` turns this off (#1).
- **Per-lesson share scope.** Lessons carry `brain_share_scope: this-agent |
  this-owner | all-agents`, set with `review decide ... --share-scope`. A
  lesson captured for a named principal is `this-owner` by default.
  Owner-only, private, restricted or secret-bearing records can never be
  `all-agents`. Packs, search, recall, briefs, exports and replication honour
  the scope. `share audit PROJECT --as PRINCIPAL` is a read-only leak probe.
  `LLM_BRAIN_SHARE_SCOPE_STAMP=0` stops the default stamp;
  `LLM_BRAIN_SHARE_SCOPE_ENFORCE=0` is a diagnostic off switch (#2).
- **Ingest transforms are recorded.** Each episode carries
  `brain_source_transforms`, `brain_source_bytes_identical`, and any
  `brain_upstream_transforms` an adapter declared (Hermes and MCP capture now
  declare theirs). `custody verify PROJECT` re-hashes every stored source and
  lists what changed on the way in. It is read-only and prints paths and
  transform names only (#3).
- **Look-alike names never merge.** A review that would supersede or merge a
  different entity with a look-alike name is held (audit `namesake-hold`).
  `review decide ... --same-entity` confirms on purpose. A second person with
  the same name gets their own record. Triage, doctor and health stop
  suggesting such merges, and packs label look-alikes with what tells them
  apart. `LLM_BRAIN_NAMESAKE_GUARD=0` and `LLM_BRAIN_PACK_NAMESAKE_LABELS=0`
  turn those off (#7).

## Packs and evaluation

- **Conflict reserve.** Packs hold 20% of the budget
  (`LLM_BRAIN_PACK_CONFLICT_RESERVE`) for open conflicts touching the task
  and show both sides together. Packs without an open conflict are unchanged.
  `=0` turns it off (#4).
- **Check evidence before acting.** Lessons record how the task they came
  from ended (`brain_source_outcome: success | failure | unknown`, also set
  with `review decide ... --source-outcome`) and the evidence path. Packs
  and recall mark a failure-derived or conflicting lesson "Check evidence
  before acting". `LLM_BRAIN_PACK_EVIDENCE_FLAGS=0` hides the marks (#5).
- **Opt-in pack layout.** `pack build --layout auto` (or
  `LLM_BRAIN_PACK_LAYOUT`) lays the same records out as a timeline, current
  value first, open conflicts side by side, or steps first, according to the
  question. The default remains `ranked`. `scripts/personal-eval.py --layout-ab`
  compares the two on a copy of a brain (#6).
- **Leak-free eval scores.** `eval run` reports leak-free scores, folds cases
  by source group, and records each case's retrieval margin in `fairness.tsv`.
  `--margin-log FILE` appends the margin and brain size per run (#7).

## Upgrade notes

- No vault migration. Storage schema 3, OKF v0.2 and the writer format are
  unchanged.
- Existing records are not retro-tagged with safeguard, share-scope or entity
  fields. Episodes captured before 0.14 show as `unrecorded` in
  `custody verify`.
- Upgrade every machine that shares a vault, so that all of them apply the
  new promotion holds and share-scope enforcement.
