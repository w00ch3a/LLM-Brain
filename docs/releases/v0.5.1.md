# LLM-Brain v0.5.1

Version 0.5.1 adds a copy-ready installation prompt for agent-guided setup. It does not change the memory format, runtime behaviour or vault schema.

## Agent-guided installation

Give [`install_prompt.md`](../../install_prompt.md) to Codex, Claude Code, Gemini CLI, Hermes Agent or another capable local agent. Before changing the machine, the prompt asks the user to confirm:

- target agent hosts and release source;
- vault and project scope;
- automatic capture and reflection behaviour;
- lexical, vector or hybrid retrieval and context budget;
- privacy, visibility and exclusions;
- Hermes MemoryProvider and optional ContextEngine settings;
- experimental capability activation;
- existing-vault compatibility or migration boundaries.

The prompt requires checksum verification, pinned dependencies, backups, synthetic smoke tests and separate reporting of source, installation and runtime state.

## Packaging

The installation prompt is included in both the polyglot plugin and standalone archives. Existing v0.5.0 release archives remain unchanged.

## Compatibility

- Reads storage schemas 1, 2 and 3.
- Keeps OKF v0.2 as canonical semantic memory.
- Requires no daemon, database or new runtime dependency.
- Preserves all v0.5.0 runtime and Hermes integration behaviour.
