# LLM-Brain v0.5.2

Version 0.5.2 replaces the pre-install settings questionnaire with a newcomer-friendly installation flow.

## One decision first

The agent now starts with three choices:

1. **Install it for me** — applies safe recommended settings.
2. **Show me options** — opens a short customisation menu.
3. **Cancel** — makes no changes.

Choosing the recommended setup does not ask about retrieval strategies, token budgets, reflection policies, project IDs, timeouts, migrations or experimental flags. Advanced controls remain available when requested.

## Safe defaults

The recommended path keeps memory local and Markdown-based, enables automatic recall and authorised capture, uses an existing vector provider or lexical fallback, retains evidence and privacy protections, and leaves migrations and experimental capabilities off.

Only the current agent host is configured. Other detected hosts are reported as optional additions.

## Compatibility

- Reads storage schemas 1, 2 and 3.
- Keeps OKF v0.2 as canonical semantic memory.
- Changes onboarding content only; runtime and vault formats are unchanged.
