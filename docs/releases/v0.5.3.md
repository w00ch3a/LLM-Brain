# LLM-Brain v0.5.3

Version 0.5.3 improves conflict-aware Hermes retrieval while preserving Markdown custody and the existing host contracts.

## Retrieval

- Indexes Hermes user content separately from assistant suggestions for personal-fact ranking.
- Routes dynamic, static and conditional questions explicitly and exposes the selected mode through bridge JSON.
- Preserves competing dates, principal boundaries and unresolved static conflicts instead of silently choosing a winner.
- Adds topic coverage for marital status, children, employment, health, social status, income, savings and sibling count.
- Rebuilds stale derived evidence indexes deterministically from custody sources.

## Compatibility and verification

- Reads storage schemas 1, 2 and 3 and keeps OKF v0.2 canonical memory unchanged.
- Keeps the existing Hermes bridge JSON and plugin configuration compatible.
- Validated with the repository self-checks, Hermes integration regression, packaged CLI checks and deterministic plugin/standalone archives.
