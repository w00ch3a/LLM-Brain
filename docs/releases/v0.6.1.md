# LLM-Brain v0.6.1

v0.6.1 is the migration-free release of the state-safe memory, reusable
procedure and release-readiness work prepared for the v0.6 line.

## What changed

- State resolution remains opt-in through `--intent current_state`; factual and
  historical retrieval retain their established behaviour.
- Commitment decisions, independent-source accounting and target-bound
  procedure capsules remain derived, bounded and non-canonical.
- Hermes keeps `memory.provider: llm-brain`, the optional context engine, its
  six configuration keys, native compressor and fail-open behaviour.
- The release gate now covers compatibility, upgrade safety, packaging,
  presentation and real Hermes source validation.

## Compatibility and rollback

No vault migration, daemon, new dependency, model training, KV-cache
integration or graph database is introduced. Existing bridge fields, factual
defaults, capsule-free runs and `ingest-source` behaviour remain compatible.
Older Hermes installations may ignore the additive state and provenance
fields. To roll back, restore the prior package and leave the schema-3 vault
in place; no migration reversal is required.

## Verification

Run `bash tests/release-readiness-self-check.sh --release` and verify that both
packaged CLIs and the Hermes manifest report the value in `VERSION`.
