# LLM-Brain v0.6.3

Version 0.6.3 is a local release candidate carrying the release-preparation
and packaging corrections after published v0.6.2.

## Compatibility

LLM-Brain remains filesystem-first with canonical Markdown and schema 3. The
Hermes integration preserves `memory.provider: llm-brain`, the optional
`context.engine: llm-brain`, the six configuration keys, native compression,
and fail-open recall/capture boundaries. No vault migration, daemon, database,
model training, or new runtime dependency is introduced.

## Verification

This candidate must pass the repository's syntax, self-check, packaging,
link, and diff checks before publication. It has not been committed, tagged,
published, installed, or applied to the live vault.
