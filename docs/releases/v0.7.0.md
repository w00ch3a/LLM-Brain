# LLM-Brain v0.7.0

Version 0.7.0 is a local release candidate. It is not a published release,
installation proof, deployment statement or live-vault migration record.

## Scope and compatibility

This candidate remains filesystem-first, uses canonical Markdown with schema 3
and OKF-v0.2, and introduces no migration, daemon, database, model-training
step or new runtime dependency. Existing vaults and records are not rewritten
by this documentation and release candidate.
No vault migration is required or performed.

Hermes defaults are unchanged: `memory.provider: llm-brain`, the optional
`context.engine: llm-brain`, the six configuration keys, native compression and
fail-open recall/capture boundaries remain supported.

## Interfaces and safety boundaries

Receipts are opt-in derived records via `search --receipt`; ordinary searches
do not write receipts. Retraction is a preview/confirm flow:

```text
llm-brain retract PROJECT_ID TARGET --reason "obsolete" --preview
llm-brain retract PROJECT_ID TARGET --reason "obsolete" --confirm TOKEN
```

The preview token must be confirmed explicitly. Confirmation records a
tombstone and does not delete source custody. No automatic forgetting or
implicit lifecycle injection is provided.

## Portability and evaluation limits

Portable exports, repair paths and lifecycle scenarios are evaluation evidence,
not proof of equivalent behaviour in another provider or deployment. Results
depend on exact source, configuration, versions, provider availability and
runner. Without a trusted local answer runner, model-answer accuracy is
unmeasured; bounded poisoning cases are not universal prompt-injection or
factual-truth guarantees.

## Notice, rollback and publication state

LLM-Brain is provided under Apache-2.0 without guarantees. Users remain
responsible for reviewing source custody, configuration, suitability, backups,
privacy and any action taken from retrieved context.

The candidate has not been committed, tagged, published, installed or applied
to the live vault. If local candidate changes are rejected, restore the
accepted source and package from the repository's governed Git workflow; do
not run migration or delete custody as a rollback shortcut.
