# LLM-Brain v0.9.1

Released 2026-10-12.

This patch release fixes where the Hermes Neural Expansion page is written.
Storage schema 3 and canonical OKF v0.2 are unchanged. No vault migration is
needed; upgrade from 0.9.0 or 0.8.x by installing the release as usual.

## Fixes

- **Private, local Neural Expansion output.** Hermes `/neural-expansion` and
  the dashboard page now write to `$HERMES_HOME/neural-expansion/` (directory
  0700, file 0600) instead of `$HERMES_HOME/llm-brain/neural-expansion/`. On
  installs where `$HERMES_HOME/llm-brain` is a symlink to the vault, 0.9.0
  wrote demo pages into the vault, where a network share could ignore the
  private permissions.
- **Fail closed.** An output directory that resolves inside the vault, or a
  filesystem that does not keep 0700/0600 modes (for example SMB/CIFS), is
  refused with an error instead of producing a shared-readable page.
