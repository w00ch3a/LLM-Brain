# LLM-Brain v0.9.2

Released 2026-10-12.

A documentation release. No code paths change. Storage schema 3 and canonical
OKF v0.2 are unchanged. No vault migration is needed; hosts already on 0.9.1
lose nothing by staying there.

## Documentation

- **New README.** A short introduction: what LLM-Brain is, measured
  real-agent results, a quick start, Hermes and Neural Expansion setup,
  multi-user brains, label lineage and upgrading. The previous README, with
  every command and setting, is now [`docs/guide.md`](../guide.md) and ships in
  the archives.
- **Real-agent results** in [`docs/real-eval-results.md`](../real-eval-results.md):
  coding memory tasks 100% with memory versus 3% without; research recall 27%,
  then 67% after the v0.8.2 fixes (10% without memory).
- **Screenshots** of Neural Expansion inside Hermes in `docs/images/`, taken
  from a demo brain with fictional content.
- **Hermes profiles.** The Hermes plugin guide and README explain that when
  llm-brain lives in a named profile, `llm-brain` must be in `plugins.enabled`
  in both that profile's `config.yaml` and the root `~/.hermes/config.yaml`;
  the dashboard serves tab files using the root config.
